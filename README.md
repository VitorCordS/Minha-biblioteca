# Minha biblioteca

Aplicação para gerenciar e organizar seus jogos, permitindo adicionar, remover e filtrar jogos por categoria.

---

## Funcionalidades

- Adicionar jogos com nome, caminho do executável, imagem e categoria.
- Remover jogos.
- Filtrar jogos por categoria.
- Buscar jogos por nome.
- Criar novas categorias.

---

## Como Usar

1. **Instale as dependências**:

   - Instale as bibliotecas necessárias:
     ```bash
     pip install -r requirements.txt
     ```

2. **Execute o programa**:
   - Inicie o script:
     ```bash
     Minha_biblioteca.py
     ```

3. A interface gráfica será aberta e você poderá usar a aplicação.
